# Tutorial GitHub

**1.** O primeiro passo é criar um repositório no GitHub.

Após esse processo, os comandos utilizados são:

1. `git clone` - Clona o repositório na máquina local.
2. `git init` - Inicia ou reinicia um repositório.
3. `git status` - Para saber quais documentos podem ser commitados.
4. `git add <nome_do_arquivo>` - Adiciona o arquivo a ser commitado.
5. `git commit -m "mensagem"` - Realiza o commit dos arquivos.
6. `git remote add origin <url>` - Adiciona o repositório remoto.
7. `git push -u origin main` - Envia o arquivo para o GitHub.
